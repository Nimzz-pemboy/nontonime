# Nontonime

Website streaming anime subtitle Indonesia tanpa perlu akun.

## Pengembangan Lokal

Butuh Node.js terpasang di komputer.

```sh
git clone <url-repository-ini>
cd <nama-folder>
npm install
npm run dev
```

## Build untuk Produksi

```sh
npm run build
npm run preview
```

## Dibangun dengan

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Video.js
